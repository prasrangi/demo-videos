# Sales agent click-through

A click-through player for the recorded Sales agent demo (Copilot with a Salesforce connection). It pauses at each of the 22 prompts and clicks, zooms to a highlight box and shows the exact text to type or the button to click. The "Pause on replies" switch also stops at each of the 18 replies.

Open `index.html` through a web server or GitHub Pages. `sales-agent-demo.mp4` must sit next to it.
