# Sales agent click-through

A click-through player for two recorded Sales agent demos (Copilot with a Salesforce connection), merged into one walkthrough of about five minutes. It pauses at each of the 27 prompts and clicks, zooms to a highlight box and shows the exact text to type or the button to click. The "Pause on replies" switch also stops at each of the 22 replies.

Steps 1 to 22 follow an account, a note, a task, a next-step update and two meetings. Steps 23 to 27 review a meeting transcript and check which actions still need an owner or deadline.

Open `index.html` through a web server or GitHub Pages. `sales-agent-demo.mp4` must sit next to it.
