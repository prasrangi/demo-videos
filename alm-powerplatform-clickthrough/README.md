# ALM PowerPlatform click-through

A click-through player for the recorded Power Platform pipeline demo (AF Pilot Agent, DEV to TEST to PROD). It pauses at each of the 38 steps, with a highlight box (yellow = you change this, blue = look here / next click, green = result) and a short caption. The "Pause at every step" switch can be turned off to stop only at the 8 changes. Idle waits are fast-forwarded.

Open `index.html` through a web server or GitHub Pages. `base.mp4` must sit next to it.
